# 🚀 React + TypeScript + Vite + Tailwind CSS

This project is an **assignment from BabyCodes** built using modern frontend technologies:  
- ⚛️ [React](https://react.dev/) – Component-based UI library  
- 📘 [TypeScript](https://www.typescriptlang.org/) – Type-safe JavaScript  
- ⚡ [Vite](https://vitejs.dev/) – Next-generation frontend tooling  
- 🎨 [Tailwind CSS](https://tailwindcss.com/) – Utility-first CSS framework  

---

## 📦 Prerequisites
Make sure you have the following installed on your system:
- [Git](https://git-scm.com/)  
- [Node.js & npm](https://nodejs.org/)  

---

## 🛠️ Installation & Running the Project

Clone the repository:
```bash
git clone https://github.com/OgunwandeBukunmi/babycodes-ass-reactjs.git

cd babycodes-ass-reactjs

```
Now inside the Git folder
```js
npm install

npm run dev
```
